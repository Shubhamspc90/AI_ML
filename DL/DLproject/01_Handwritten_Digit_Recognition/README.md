# Handwritten Digit Recognition using ANN

## Project Overview

This project builds an Artificial Neural Network (ANN) using TensorFlow and Keras to recognize handwritten digits from the MNIST dataset.

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
